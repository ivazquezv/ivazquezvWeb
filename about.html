Iván Vázquez Vidador

Lenguajes y desarrollo web
Desarrollo con Java y JavaScript, junto con HTML5 y CSS3 para la estructura y presentación de interfaces web. Trabajo con SQL para la consulta y gestión de datos.
Backend y arquitectura
Desarrollo de aplicaciones y APIs REST con Spring Boot, Spring Framework e Hibernate. Enfoque en arquitectura modular, separación de responsabilidades y código mantenible.
Frontend e interfaces
Construcción de interfaces adaptables a móvil, tablet y escritorio con HTML, CSS, JavaScript y Vite. Atención a la accesibilidad, la navegación y el rendimiento. Experiencia con WordPress y WooCommerce.
Pruebas y calidad
Uso de JUnit y Postman para comprobar lógica de aplicación y APIs. Depuración con las herramientas del navegador y revisión de rendimiento y accesibilidad con Lighthouse.
Seguridad y datos
Interés especializado en cifrado, seguridad web y control de acceso. Creador de Encryptify, una suite modular de cifrado orientada a educación, análisis forense y protección de la información.
Git y despliegue
Control de versiones con Git y GitHub, gestión de ramas y documentación técnica. Publicación en Netlify, configuración de dominios, DNS y certificados SSL. Trabajo con Linux, Bash y PowerShell.
Desarrollo aplicado: WodIO
Creador de WodIO, una plataforma web para boxes de CrossTraining y gimnasios. Integra la gestión de clases, horarios, reservas y asistencia con el seguimiento del progreso del atleta.
IA y mejora de procesos
Responsable de integración de inteligencia artificial en Saltoki, donde también desempeño funciones de planogramador y jefe de equipo. Conecto herramientas digitales con necesidades operativas y procesos de trabajo.
